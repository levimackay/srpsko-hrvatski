Male (M) (Words ending with a consonant are male unless otherwise stated, if a word has the male marker it is only there for clarification where there might be confusion.) Female (F) (Words ending with an "a" are female unless otherwise stated, if a word has the feminine marker, this means a similar word is a different gender and it is only there for clarification.) Neuter (Neu) (Words ending in an "e" or "o" are neuter unless otherwise stated, if a word has the neuter marker, this means a similar word is a different gender and it is only there for clarification, for example "veće" and "većer".)
